Direct answers about PhoneAI's local phone runtime, on-device models, native mobile Skills, data flow, LiveLand, and Mac Gateway inference.

Privacy details Framework details

What is PhoneAI?

PhoneAI is a mobile-native local AI Agent framework for phones and edge devices. Its iOS runtime runs on-device models and native iOS Skills on the phone by default, with optional Mac Gateway remote inference for heavier local models.

Which PhoneAI project is this?

PhoneAI (this project) is unrelated to the Android automation repo "rohanarun/phoneai" or the "phoneai" GitHub organization. Android app-store search results may also show a separate app with the same name. This site documents the open-source PhoneAI framework at github.com/tangzhiyin/PhoneAI.

What kind of framework is PhoneAI?

PhoneAI is a mobile-native Agent framework for phones and edge devices. It combines local model execution, native mobile Skills, permission-scoped data access, Live / LiveLand interaction, and optional LAN Mac inference.

How does PhoneAI handle chats, images, and personal data?

In PhoneAI's local runtime, chat, images, and personal data stay on device by default. Web Search, opening a URL, and paired Mac remote inference are explicit user-triggered capabilities.

How does PhoneAI work as a local mobile Agent?

PhoneAI uses local models, native mobile Skills, permission boundaries, fully offline local execution, and user-triggered network capabilities for Web Search, URL reading, and Mac remote inference. Its iOS runtime implements native mobile Skills and local model execution.

How does PhoneAI work as a mobile-native Agent framework?

PhoneAI is designed for mobile and edge-device constraints: iOS permissions, app lifecycle limits, memory budgets, model downloads, widgets, Shortcuts, Dynamic Island, voice, camera, and optional LAN Mac inference.

What models does PhoneAI use?

PhoneAI uses Gemma 4 E2B and E4B via LiteRT-LM for local language tasks, and MiniCPM-V 4.6 for image understanding and LIVE camera scenarios.

What native iOS Skills can PhoneAI use?

PhoneAI Skills can work with native iOS capabilities such as Calendar, Reminders, Contacts, Clipboard, HealthKit, translation, images, and explicit Web Search, subject to iOS permissions and Skill allowlists.

What is PhoneAI Gateway?

PhoneAI Gateway pairs an iPhone with a Mac on the same local network. The Mac can provide heavier inference through Ollama or supported CLI providers, while the iPhone keeps the agent UI, Skills, permissions, and task flow.
